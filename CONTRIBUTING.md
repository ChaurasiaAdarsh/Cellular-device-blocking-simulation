# Contributing Guidelines

Thank you for your interest in contributing to the IMEI Blocking & Unblocking Simulation project!

## Scope of the Project

This repository is an independent proof-of-concept simulation developed for educational and architectural study. Contributions should focus on:
- Improving architectural clarity and documentation
- Enhancing test coverage (unit and integration tests)
- Optimizing code structure and asynchronous batch handling
- Improving UI ergonomics and validation feedback

## Development Workflow

1. Fork or branch from `main`.
2. Ensure you follow standard language conventions:
   - Java: camelCase for methods/variables, PascalCase for classes, lowercase for packages.
   - JavaScript/React: PascalCase for components, camelCase for functions and hooks.
3. Test changes locally before submitting a pull request.
4. Keep commits descriptive and atomic.
